# Tasks

Work is organized in three levels: **Phase → Task → SubTask**. Phases are sequential. Preserve task order when checkpointing; completion requires evidence.

| Symbol | Status | Meaning |
| --- | --- | --- |
| ⬜ | pending | 尚未开始 |
| 🔄 | in_progress | 已开始，尚未完成 |
| ✅ | done | 有明确完成证据 |
| ⏸️ | blocked | 已确认的阻塞，需注明原因 |

Task/Phase 状态由 SubTask 推导：有进行中项则为 in_progress；无进行中项而存在阻塞则为 blocked；全部完成才为 done；尚未开始为 pending。当前已开展本机环境与最小推理验证；状态以各任务标记为准。用户明确暂缓的第二台机器核对单独保留，不计入当前 2.1 的关闭条件，也不计作已验证。
